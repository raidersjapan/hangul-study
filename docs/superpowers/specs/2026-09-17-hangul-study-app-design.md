# ハングル学習アプリ 設計書

作成日: 2026-09-17

## 目的

完全にハングル未学習の初心者が、スマートフォンのブラウザで基本字母（母音・子音・濃音・複合母音）の読み書きと発音を学べるWebアプリを作る。

## 対象ユーザー

- ハングルを一から学びたい初心者（想定利用者は開発者本人）
- スマートフォンのブラウザで日常的に使う

## スコープ

含む:
- 字母一覧・解説（学習タブ）
- クイズ（字母→発音選択、発音→字母選択）
- 手書き練習（Canvas、正誤判定なしの自己練習）
- 発音音声再生（Web Speech API）
- 学習進捗のブラウザ内保存（localStorage）

含まない（将来検討）:
- 単語・文章レベルの学習
- 手書き文字のOCRによる正誤判定
- サーバーサイド・アカウント機能・複数端末間の進捗同期
- ネイティブアプリ化

## 技術構成

- 素のHTML / CSS / JavaScript。ビルドツール・フレームワークは使わない。
- 単一ページアプリ（SPA）。画面下部のタブバーでJSによりビュー切り替え。
- モバイルファーストのレイアウト（タップしやすい大きめのUI）。

## ファイル構成

```
korean-hangul-app/
├── index.html          # 画面構造（タブ切り替え式）
├── style.css           # デザイン（モバイルファースト）
├── js/
│   ├── data.js         # ハングル字母データ（子音・母音・発音・説明）
│   ├── storage.js      # localStorage経由の進捗管理
│   ├── speech.js       # Web Speech APIラッパー（発音再生）
│   ├── study.js        # 学習タブのロジック
│   ├── quiz.js         # クイズタブのロジック
│   ├── writing.js      # 書き取りタブのロジック（Canvas）
│   └── app.js          # タブ切り替え・初期化
```

## データモデル

`data.js` に全字母を段階分けして定義する。

```js
const VOWELS_BASIC = [
  { id: "v-a", char: "ㅏ", romanization: "a", stage: "vowel_basic", desc: "..." },
  // ㅑㅓㅕㅗㅛㅜㅠㅡㅣ 含め基本母音10字
];

const CONSONANTS_BASIC = [
  { id: "c-g", char: "ㄱ", romanization: "g/k", name: "기역(キヨク)", stage: "consonant_basic", desc: "..." },
  // 基本子音14字
];

const CONSONANTS_TENSE = [
  // ㄲㄸㅃㅆㅉ 濃音5字, stage: "consonant_tense"
];

const VOWELS_COMPOUND = [
  // ㅐㅔㅘㅙ など複合母音11字, stage: "vowel_compound"
];
```

学習段階（4段階、この順で進める想定）:
1. `vowel_basic` — 基本母音10字
2. `consonant_basic` — 基本子音14字
3. `consonant_tense` — 濃音5字
4. `vowel_compound` — 複合母音11字

クイズ・書き取り練習は、選択中の段階の字母のみを出題・表示対象とする。

## 画面仕様

### ① 学習タブ（字母一覧・解説）
- 段階を選ぶセレクタ/タブ（母音・子音・濃音・複合母音）
- カード形式で字母を一覧表示
- カードタップで発音再生（Web Speech API）
- カード内容: ハングル文字、ローマ字読み、日本語の名称・発音のコツ

### ② クイズタブ
- 出題形式（ミックス出題）:
  - 字母を見せて発音（ローマ字/名称）を4択から選ぶ
  - 発音を音声で聞かせて字母を4択から選ぶ
- 出題範囲は選択中の学習段階から
- 正誤に応じてlocalStorageの正答率データを更新
- 間違えた字母は次回以降の出題頻度を上げる（直近の正答率が低い字母を優先的に出題する簡易ロジック）

### ③ 書き取りタブ
- Canvas要素に指/マウスで描画
- お手本の字母を薄く表示するなぞり書きガイド（トグルでON/OFF可能）
- 「消す」「次の字母へ」ボタン
- 正誤判定は行わない自己練習ツール

### ④ 進捗タブ
- 学習段階ごとの正答率・回答数を一覧表示
- 「進捗をリセット」ボタン（confirm後、localStorageをクリア）

## 永続化

- localStorageに以下の形式で保存:
  ```js
  {
    "c-g": { attempts: 5, correct: 4, lastSeen: 1234567890 },
    ...
  }
  ```
- localStorage利用不可の環境では保存をスキップし、メモリ内state（そのセッション中のみ有効）で動作を継続する。

## エラーハンドリング

- Web Speech APIの音声リストは非同期で読み込まれるため、`voiceschanged`イベントを考慮して安全に初期化する。音声合成が利用できない環境では発音再生ボタンを非表示にする。
- Canvas未対応ブラウザでは書き取りタブに簡易な非対応メッセージを表示する。
- localStorageが使えない場合（プライベートブラウズ制限など）は進捗保存をスキップし、アプリの他機能は通常通り動作させる。

## テスト方針

- 自動テストのビルド環境は導入しない。
- 実装後、ブラウザで以下を目視確認する:
  - 学習→クイズ→書き取り→進捗の一連の操作フロー
  - スマートフォン幅（375px程度）でのレイアウト崩れがないか
  - 音声再生、Canvas描画、localStorageへの保存・読み込みが正しく動作するか
